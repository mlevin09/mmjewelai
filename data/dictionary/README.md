# Domain Dictionary artifacts

`v1.0.0.json` is the proposed initial EN/RU vocabulary bundle. It is intentionally small and marked
`proposed_pending_domain_review`; it is not an exhaustive or production-authoritative jewelry
ontology.

The artifact contains terminology and normalization aliases only. It contains no gemstone dimensions,
weight-to-size data, manufacturing tolerances, or estimates. See the
[Domain Dictionary specification](../../specs/dictionary/README.md) for the contract and compatibility
policy.
