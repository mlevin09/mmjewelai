# Role profile artifacts

`v1.0.0.json` is the initial complete registry for the six canonical conversational roles.
It is versioned separately from the Jewelry Design Schema and is marked
`proposed_pending_domain_review`; it is not an authorization or production permissions catalog.

The contract and compatibility policy are documented in the
[Role Profiles specification](../../specs/roles/README.md). Published profile versions must remain
immutable. A changed policy requires a new artifact version and validation as a complete bundle.
