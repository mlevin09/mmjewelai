# Rules Engine artifacts

`v1.0.0.json` contains nine proposed deterministic rules over the five Question Catalog targets. It
pins Schema, Role Profile, Domain Dictionary, and Question Catalog versions. The seed is deliberately
small and marked `proposed_pending_domain_review`; it is not a production jewelry rules corpus.

The artifact contains only allowlisted conditions/actions and stable metadata. It contains no Python,
generic expressions, user-facing question wording, factual gemstone dimensions, Knowledge Base
records, or unapproved assumption/default rules. See the
[Rules Engine specification](../../specs/rules/README.md).
