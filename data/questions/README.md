# Question Catalog artifacts

`v1.0.0.json` is the proposed initial EN/RU Question Catalog. It contains five semantic questions,
explicit wording for all six canonical roles, pinned cross-artifact versions, and validated examples.
It is intentionally small and is not a production-complete question library.

The artifact contains presentation and answer-contract metadata only. It has no conditions,
priorities, sequencing, readiness criteria, question budgets, or ask/derive/assume/block behavior.
See the [Question Catalog specification](../../specs/questions/README.md) for target syntax, rendering,
locale behavior, and compatibility policy.
