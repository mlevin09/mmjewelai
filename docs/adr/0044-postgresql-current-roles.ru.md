# ADR 0044 — Единый текущий PostgreSQL-каталог ролей (RU TRANSLATION)

Статус: направление утверждено Owner; реализация ожидает независимой проверки. Дата: 2026-11-16.

## Контекст

ROLES-001 заменяет шестиролевой JSON runtime. Совместимость с его историческими сессиями
исключена; удаление общих данных не разрешено. Утверждённый Registry содержит 21 каноническую
роль, девять черновых паспортов и 36 черновых proto-persona.

## Решение

Создать одну таблицу `roles` с девятью указанными Owner колонками. Миграция
`0021_roles_foundation` импортирует полное исходное содержание. Явный повторный импорт
транзакционен: одинаковые записи сохраняют revision, изменённые увеличивают его.
PostgreSQL — рабочий источник; обычный startup не читает Drive и не создаёт резервный каталог.

Runtime читает текущие строки без устаревающего кэша определений. Старые role artifact поля
в остальных wire/evidence контрактах — исторические метаданные, не выбор каталога ролей.
Существующие pins Dictionary/Questions/Rules/Prompts продолжают проверяться.

Выбор и порядок Studio находятся в конфигурации приложения (девять ролей по умолчанию),
не в флагах БД. Все 21 доступны через authenticated read endpoints. Профессиональная роль
не предоставляет прав организации. Черновые паспорта/persona остаются явно непроверенным
исходным контекстом, не исполняемой политикой общения. Утверждённая role-specific policy
не импортируется. Вопросы используют одну EN/RU формулировку; существующий механизм
предложений sourced-with-uncertainty применяется одинаково, без автоматического принятия,
confirmation или обхода LOCK. Дублирующие правила по ролям не создаются.

FK сессии добавляется NOT VALID: существующие строки сохраняются, новые записи проверяются.
Общие данные не очищаются. Шесть старых ID и объединённые RR aliases недоступны для выбора.
Downgrade отказывается удалять роли, используемые сессиями, или изменённые после импорта.

## Альтернативы и последствия

Отклонены: два каталога, legacy aliases, таблицы версий/истории ролей, автоматический перевод
и превращение persona в system prompt. Изменения текущей роли намеренно влияют на последующие
чтения контекста. Исторические определения не воспроизводятся. Полные исходные документы
и хеши импорта сохранены; английские названия без утверждённого источника остаются null.

Studio UI, providers, активация Knowledge, выполнение shared migration и deployment исключены.
PostgreSQL должен пройти существующий независимый disposable-DB gate; SQLite не квалифицирует
ARRAY/JSONB и фактическую FK-миграцию.
