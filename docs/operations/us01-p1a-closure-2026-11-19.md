## Root cause and correction

`checked_reply` skipped universal save assertions when their predicate preceded the
quantifier. In the opposite order it sliced away leading Not/Не, then tried to
recognize that discarded negation. GET uses the same checker, so truthful retained
replies were incorrectly rejected as invalid durable history.

The correction checks complete assertion clauses in either word order, binds negation
to its quantifier/save predicate, and checks every save predicate in the clause.
Unrelated denials and an earlier negative assertion cannot exempt another positive
claim. Accepted/verified/committed fact qualifiers remain permitted, subject to the
unchanged named-fact/authority checks. Such universal tokens are distinguished from
stone-instance EACH/PER allocation; a scoped fact assertion cannot authorize an
allocation elsewhere. No Matrix/SO, State, receipt/read contract, Parser, schema,
hash, provenance, migration, provider setting or UI behavior is changed.

# RU — исправление P1-A

Перевод EN MASTER. Developer evidence не является независимой приёмкой.
Исходные backend/combined/integration SHA приведены выше.

Причина: checker пропускал утверждение с predicate перед all/все, а при обратном
порядке отрезал Not/Не и пытался найти его в оставшемся фрагменте. GET вызывает тот
же checker, поэтому валидные сохранённые ответы ошибочно становились invalid history.
Исправление проверяет полную assertion clause при любом порядке, связывает отрицание
с quantifier/predicate и проверяет каждый save predicate. Постороннее отрицание или
предыдущее отрицательное утверждение не оправдывает новое положительное. Qualifiers
accepted/verified/committed сохраняются с прежними named-fact/authority проверками.
Универсальный квантор над сохранёнными фактами отличён от EACH/PER для камней;
это не разрешает allocation в другой части ответа. Matrix/SO, State, contracts,
Parser, schema/hashes/provenance, migrations, provider settings и UI не меняются.

Фактический RED→GREEN соответствует таблице EN: ложные Saved all / Сохранены все
сменились с model на fallback/invalid_reply; правдивые Not all / Не все сменились
с fallback на неизменённый model text. Точные EN/RU входы приведены выше. State
по-прежнему содержит только earrings/gold/white; sapphire/count/group/allocation
не добавлены. HTTP проверки подтверждают restart readback, неизменные receipts и
SQLite bytes, одну Message/receipt, ровно две revisions, idempotency и409 при
изменении turn/revision. Сохраняются qualified/unrelated-negation, tamper, LOCK,
tenant/CAS и pending recovery controls.

Проверены настоящие четыре старые synthetic записи независимого review, а не
новая имитация истории. Оригинал сохранён; копия открыта mode=ro. Два валидных
старых model replies:500 до исправления,200 после с точным полным response.
